# Trabalho-AV2-_-phyton-_Coding# Calculadora em Python

## Descrição

Este projeto é uma calculadora desenvolvida em Python que funciona diretamente no terminal.

O aplicativo permite realizar operações matemáticas básicas através de um menu interativo.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Sair do programa
